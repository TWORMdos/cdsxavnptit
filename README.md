# Báo cáo chuyển đổi số cấp xã 2026

Trang báo cáo tĩnh được chuyển từ tài liệu tổng hợp VNPT-IT tháng 09/2026. Giao diện, nội dung, chức năng lọc và font Be Vietnam Pro đều được nhúng trong `index.html`. Trang không cần cài đặt thư viện hoặc máy chủ ứng dụng.

## Đưa lên GitHub Pages

1. Đưa `index.html` vào thư mục gốc của nhánh sẽ xuất bản, hoặc vào thư mục `docs/` của nhánh đó. Có thể tải thêm `.nojekyll` để GitHub Pages phục vụ tệp HTML trực tiếp.
2. Trong kho GitHub, mở **Settings → Pages**.
3. Ở **Build and deployment**, chọn **Deploy from a branch**, chọn nhánh và đúng thư mục chứa `index.html`, rồi bấm **Save**.

Hướng dẫn chính thức: [Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

**Lưu ý trước khi đăng công khai:** Báo cáo có số liệu kế hoạch kinh doanh, doanh thu dự kiến và mô tả công việc nội bộ. GitHub Pages có thể công khai trang kể cả khi kho lưu trữ là riêng tư, tùy gói dịch vụ. Hãy rà soát phạm vi thông tin được phép công bố.

Font Be Vietnam Pro: bản quyền thuộc [Be Vietnam Pro Project](https://github.com/bettergui/BeVietnamPro), sử dụng theo giấy phép OFL được đính kèm trong phần chú thích của `index.html`.
